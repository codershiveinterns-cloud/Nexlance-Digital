Nexlance Template License Key Registry
======================================

How to use
----------
- Add one line per generated license key.
- Keep the license key as the primary identifier.
- Update Status when a key is redeemed.

Format
------
Template Name | Template ID | License Key | Status | Issued To Email | Used By Email | Created At | Used At

Examples
--------
Startup Landing | startup-landing-template | STARTU-ABCD-EFGH | active | customer@example.com |  | 2026-03-16T12:00:00.000Z |
Fashion Store | fashion-store-template | FASHIO-QWER-TYUI | used | buyer@example.com | buyer@example.com | 2026-03-16T12:10:00.000Z | 2026-03-16T12:20:00.000Z

Notes
-----
- Production source of truth: Firestore collection `template_licenses`
- Fallback local source: browser localStorage key `nexlance_template_license_records`
- Purchase records may also store the key under `nexlance_template_purchases_<email>`
